# Brand assets

Everything here is generated by [`generate.py`](generate.py) from one set of
constants. Edit the constants, not the output.

```sh
python3 assets/generate.py            # SVGs and Android vectors
pip install cairosvg pillow
python3 assets/generate.py --png      # also re-rasterise the PNGs
```

## Provenance

The mark is a vector reconstruction of the
[VocaHQ avatar](https://avatars.githubusercontent.com/u/312860025), which is
only published as a 460×460 raster — too small for the 1024×1024 App Store
icon, and not usable at all for an Android vector drawable.

The geometry was measured off that raster rather than eyeballed: stroke widths
and radii by radial scan, colours by sampling. Two findings shaped the result.
Every stroke in the mark is the same width (18 units at 460px). And the sound
arcs are *elliptical*, not circular — their radius falls from 165.6 to about
141.6 between the horizontal and the arc ends, which is why a circular trace
never quite lands. The yoke, by contrast, is a true circle.

The reconstruction renders within 1% of the source at 460px and stays sharp at
any size.

## Outputs

| File | Used by |
| --- | --- |
| `vocaphone-logo.svg` | round badge — the avatar form |
| `vocaphone-logo-512.png` | README |
| `vocaphone-mark.svg` | the microphone alone, transparent |
| `vocaphone-app-icon.svg` | square full-bleed icon, source of the app icons |
| `vocaphone-play-store-512.png` | Play Console listing icon |
| `../ios/VocaPhoneApp/Assets.xcassets/AppIcon.appiconset/` | iOS app icon |
| `../android/app/src/main/res/drawable/ic_launcher_*.xml` | Android adaptive icon |
| `../server/app/webui/favicon.svg` | gateway WebUI and API docs |

The app icons are full-bleed squares rather than the round badge: iOS applies
its own squircle mask and Android its own adaptive-icon mask, so a circle
inside the square would leave dead corners. The mark spans 70% of the icon
width, which keeps it legible at 60pt while staying inside the Android 72dp
visible area.

`icon-1024.png` and the Play listing icon are written as RGB with no alpha
channel — App Store Connect rejects an app icon that carries one. The iOS 18
dark and tinted variants keep their transparency on purpose, because the
system draws its own field behind them.
