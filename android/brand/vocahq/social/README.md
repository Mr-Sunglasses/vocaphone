# Talk-to-us marks

Official Discord, X, and GitHub marks, plus a generic mail envelope. For About screens and the same Talk to us row across the family.

| File | Use |
| --- | --- |
| `discord.svg` | Discord, https://discord.gg/t6muquAJbm |
| `x.svg` | X, https://x.com/vocahq. Label it X, not Twitter. |
| `github.svg` | GitHub issues |
| `mail.svg` | hello@vocahq.com |

## Usage

- SVG, 24 viewBox. Draw at 16px in a text button, 18 to 20px in an icon button.
- `fill` is `currentColor`. Do not hard-code Discord blurple, X black, or GitHub black.
- Iron-white (Linux): ink `#14231C` on paper, or cream `#F2F6F2` on the Linux green `#1a7f4e` if the button is filled.
- Dark Win-style: cream `#F2F6F2` on charcoal, or `#0F6B57` if the control is a text link on dark.
- Keep the visible label next to the icon (Discord, X, Email). Icon-only needs an accessible name.
- Do not redraw these. Product agents consume these files.

Trademarks stay with Discord, X/Twitter, and GitHub. We use them to name those places.
