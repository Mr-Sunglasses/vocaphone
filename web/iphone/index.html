iPhone · public TestFlight

private voice typing,
on your iPhone.

VocaPhone needs iOS 17 or newer. The quickest way on is the public TestFlight beta, which needs nothing but an iPhone. A TestFlight build expires after 90 days and the beta has a tester limit, so this guide covers the other way in: a Mac with Xcode, an Apple signing team, and a physical iPhone. There is no App Store release yet.

before you begin iOS 17+ macOS + Xcode Apple signing physical iPhone
the short path

install, choose a model, dictate.

The gateway is optional. Choose and download an on-device model during setup if you want speech-to-text to stay entirely on the iPhone.

  1. 01

    Get the source

    Clone the repository with Git LFS so the native model runtimes are present.

    git lfs install
git clone https://github.com/VocaHQ/vocaphone.git
cd vocaphone
git lfs pull
  2. 02

    Prepare Apple signing

    Open ios/VocaPhone.xcodeproj, choose your Apple development team, and configure matching App Group capabilities for the app, keyboard, and Live Activity targets. If the VocaHQ identifiers are unavailable to your team, replace them consistently in the project configuration and entitlements first.

  3. 03

    Install on a physical iPhone

    Connect the iPhone, select it as the run destination, build VocaPhoneApp, open the installed app, and grant microphone access.

  4. 04

    Choose on-device speech-to-text

    In VocaPhone setup, choose an on-device model, download it, and wait for its integrity check to finish. No gateway address or token is needed for this mode.

  5. 05

    Enable the keyboard

    Open Settings → General → Keyboard → Keyboards, add VocaPhone, and enable Full Access so the keyboard and containing app can share the current dictation state.

  6. 06

    Try a real text field

    Open Notes, select the VocaPhone keyboard, dictate, finish the recording, and return to insert the transcript. iOS does not permit keyboard extensions to access the microphone, so the companion app owns recording while the model still runs on the iPhone.

optional path

want larger models or shared compute?

Pair VocaGateway after the phone works. Gateway mode sends the recording to hardware you configured; it is self-hosted, but it is not on-device. Protect the connection with a trusted LAN, private encrypted network, or HTTPS.
